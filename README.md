# xlamBOT

Репозиторий необходимых файлов для установки и обновления бота. Исходники, тесты и инструменты сборки убраны из текущей ветки.

**[Скачать веб-установщик — около 2,9 МБ](https://github.com/Olegu621/xlamBOT-updates/releases/download/scripts-1/xlamBOT-Web-Setup-0.8.16.exe)**

Установщик скачивает все файлы программы из этого репозитория и проверяет SHA-256. Останавливает бот, если он открыт, сохраняет резервную копию прежней установки, удаляет её и устанавливает новую в ту же папку. Настройки, профили, очередь, модели и разметка сохраняются. Резервные копии находятся в `%LOCALAPPDATA%\xlamBOT\backups`.

После установки бот автоматически проверяет обновления при запуске и раз в час. Обновления модулей и панели скачиваются из [релизов](https://github.com/Olegu621/xlamBOT-updates/releases), проверяются по подписи и применяются после остановки игры и записи кадров. Переключатель находится в панели.

Файлы релиза: маленький EXE-установщик, полный архив программы `xlamBOT-runtime-0.8.16.zip`, пакет скомпилированных модулей и файлов панели `scripts.zip`, подписанный `manifest.json`. Python-исходников приложения в пакетах обновлений нет.
