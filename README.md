# Обновления скриптов xlamBOT

Отдельный канал обновлений для xlamBOT 0.8.16 и новее. Бот опрашивает GitHub Releases при запуске и раз в час. Проверяет подпись Ed25519 и SHA-256, скачивает скрипты, ожидает остановки всех ботов и записи кадров, затем перезапускается. Настройки, история, профили, модели, разметка и LDPlayer сохраняются.

В панели можно отключить автообновление или проверить релиз вручную. Без интернета бот продолжает работать. Неудачный запуск обновления восстанавливает предыдущую ревизию при следующем запуске.

## Публикация

Каждый пакет содержит полный актуальный набор скриптов и файлов панели: это позволяет пропускать промежуточные релизы. EXE, библиотеки, модели и пользовательские данные в пакет не входят. Изменения загрузчика или зависимостей требуют нового установщика.

1. Подготовьте исправленный исходный проект и проверьте его.
2. В Python с `cryptography` выполните:

```powershell
python publish.py --source scripts --key "$env:LOCALAPPDATA\xlamBOT-publisher\update-signing-key.pem" --revision 2
```

3. Создайте обычный публичный релиз `scripts-2` и загрузите **оба** файла:

```powershell
gh release create scripts-2 dist/2/scripts.zip dist/2/manifest.json --repo Olegu621/xlamBOT-updates --title 'Скрипты: ревизия 2' --notes 'Описание изменений'
```

Изменяемые скрипты находятся в `scripts/`; архив генерируется из этой папки. Номер ревизии всегда увеличивается. Для отката выпустите предыдущие исправные скрипты под новым номером. Не изменяйте уже опубликованные релизы. Закрытый ключ хранится только локально вне репозитория; сохраните защищённую резервную копию. Потеря ключа требует нового установщика с новым публичным ключом.

## Где находятся файлы

- `%LOCALAPPDATA%\xlamBOT\updates\state.json` — настройка и активная ревизия.
- `updates\releases\<номер>\content` — проверенные скрипты.
- Предыдущие ревизии сохраняются для восстановления.
- Основной проект и установщики: https://github.com/Olegu621/xlamBOT

Обновления выполняют код владельца этого репозитория. Подпись не даёт подменить пакет без закрытого ключа.

## Загрузчик

В `bootstrap/` находятся исходники встроенного загрузчика, установщик и тесты. Они не обновляются пакетами скриптов. Для сборки загрузчика используйте зависимости и ресурсы основного проекта, замените Python-модули на `scripts/`, файлы загрузчика на `bootstrap/`, затем соберите `xlambot.spec` и `installer.iss`. Модели и ресурсы игрового распознавания берутся из основной сборки.

Проверки загрузчика: `python bootstrap/test_updates.py` (нужны requests и cryptography).
