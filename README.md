# xlamBOT

Необходимые файлы программы и обновления находятся в **[Olegu621/xlamBOT-updates](https://github.com/Olegu621/xlamBOT-updates)**. Исходники убраны из текущих веток обоих репозиториев.

## Скачать

[Маленький веб-установщик xlamBOT](https://github.com/Olegu621/xlamBOT-updates/releases/latest)

Установщик скачивает все файлы программы из нового репозитория, проверяет контрольную сумму, останавливает открытый бот, сохраняет резервную копию, удаляет старую установку и заменяет её новой. Настройки, профили устройств, очередь, модели и разметка сохраняются.

После установки бот автоматически получает обновления скриптов из GitHub Releases нового репозитория. Обновления применяются после остановки игры и записи кадров. Переключатель автообновления находится в панели.

Этот репозиторий оставлен как страница перехода. Старые релизы и история Git доступны для восстановления прежних версий; новые установщики и файлы обновлений публикуются в xlamBOT-updates.
