# xlamBOT

Все необходимые файлы установки и обновления находятся в этом репозитории. Python-исходники приложения и инструменты сборки не публикуются.

**[Скачать красивый веб-установщик 0.8.17 — около 2,9 МБ](https://github.com/Olegu621/xlamBOT/releases/download/scripts-2/xlamBOT-Web-Setup-0.8.17.exe)**

Установщик скачивает программу из релиза этого репозитория и проверяет SHA-256. Если бот открыт, установщик останавливает его, сохраняет резервную копию старой установки, заменяет программу и восстанавливает настройки, профили устройств, очередь, историю, модели и разметку. Резервные копии: `%LOCALAPPDATA%\xlamBOT\backups`.

## Переход с xlamBOT-updates

Сборки 0.8.16 содержат прежний адрес обновления в EXE. Один раз запустите установщик **0.8.17** поверх прежнего бота. После этого бот получает подписанные обновления из [релизов xlamBOT](https://github.com/Olegu621/xlamBOT/releases) при запуске и раз в час. Переключатель и ручная проверка находятся в панели.

Обновления модулей применяются после остановки автоигры и записи кадров. Подпись Ed25519 и контрольные суммы проверяются перед запуском; предыдущая ревизия восстанавливается при следующем запуске, если новая не смогла запуститься.

В текущей ветке: `manifest.json`, `scripts.zip`, маленький установщик и описание архива программы. Полный архив программы лежит в релизе, чтобы не раздувать Git. Пакет `scripts.zip` содержит скомпилированные Python-модули и файлы панели. Обновления EXE и зависимостей требуют нового установщика.

Релиз `scripts-1` перенесён как архив с исходными файлами 0.8.16; его старый установщик не используется после миграции. Актуальное обновление модулей — `scripts-3`; установщик и полный архив программы — `scripts-2`.


В карточке каждого устройства доступна ручная калибровка выбора бойца: точки на снимке, сетка карточек, поиск, сортировка и области чтения имени и трофеев. Настройки сохраняются отдельно для каждого устройства.
